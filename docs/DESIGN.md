# Design direction

## Identity

Primary wordmark:

```text
TRAYLOR
Family Game Station
```

The interface should feel like a premium living-room product, not a desktop file browser. It is inspired by the restraint and focus behavior of modern streaming interfaces without copying a proprietary brand or logo.

## Priority order

1. Color and material system
2. Main dashboard and CoverFlow
3. Typography and icon treatment
4. Menus, dialogs, game details, and utilities
5. Splash and transition polish

## Visual tokens

- Canvas: `#05070B`
- Elevated surface: translucent midnight navy
- Primary text: `#F5F7FA`
- Secondary text: `#A8B0BE`
- Accent: `#0A84FF`
- Focus glow: cool blue with restrained bloom
- Cover layout: one horizontal row; selected item raised and enlarged
- Typography: Inter where licensing and Aurora packaging permit it

## Main-screen goals

- Game art remains the focal point.
- One horizontal row of covers is visible at a time.
- The selected game has a subtle scale increase and glow.
- Profile, disc, RSS, and diagnostic panels are hidden by default.
- Labels are readable from across a living room.
- Motion is short and calm; avoid exaggerated 3D carousel effects.
